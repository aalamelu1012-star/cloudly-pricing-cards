# Cloudly — Responsive Product Pricing Cards

Project 03. Built with semantic HTML, CSS and vanilla JavaScript.

## Run
Extract and open index.html in a modern browser. No build is required. Google Fonts uses an internet connection.

## Features
- Three responsive SaaS pricing cards
- Monthly / yearly billing switch with 20% annual savings
- CSS transition and transform hover effects
- Most Popular and Best Value badge ribbons
- Accessible switch, keyboard controls and reduced motion support
- Plan-selection dialog and FAQ disclosures

## Pricing
Starter: free. Pro: $15 monthly or $144 yearly ($12/month equivalent). Team: $30 monthly or $288 yearly ($24/month equivalent).

## Code
index.html: semantic structure and plan content.
style.css: CSS Grid, Flexbox, responsive breakpoints, badges and transitions.
app.js: click listeners, billing state, DOM price updates and selection dialog.

This is a UI demonstration; no payments or subscriptions are created.
